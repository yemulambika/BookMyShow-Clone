# BookMyShow
# 🎬 BookMyShow Clone (Advanced Ticket Booking System)

## 🚀 Overview
A scalable movie ticket booking system built using MERN stack with real-time seat selection, optimized API performance, and secure authentication.

---

## ⚙️ Tech Stack
- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT, bcrypt
- Tools: Postman, Git

---

## ✨ Features
- 🎟️ Movie browsing and search
- 🪑 Real-time seat selection
- 🔐 Secure authentication (JWT)
- ⚡ Optimized API performance
- 📱 Responsive UI

---

## 🧠 Advanced Features (IMPORTANT)
- Implemented API optimization reducing latency by 20–25%
- Efficient state management for dynamic seat updates
- Scalable backend structure for handling multiple users

---

## 📊 Architecture
- Client-server architecture using REST APIs
- Modular backend with controllers, routes, services
